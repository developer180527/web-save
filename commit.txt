Round out settings, and fix the file picker

Browser extension and About join the settings panel. Extension status
needed no new plumbing: the capture server already stamps ext.last_seen
and ext.version into vault meta on every call, so this is a typed read
over data that was being recorded all along. It reports last contact
rather than a live socket, because the capture server runs in the Tauri
build and this app has none — which also means it keeps working when the
engine is running and this app is only looking on. "Connected" allows
twelve hours, since the extension calls in only when something is saved
and a tighter window would report a working setup as broken over a quiet
afternoon.

About reads version and build from the bundle rather than hard-coding
them, so they cannot drift from what shipped.

Replaces file_picker with file_selector. pub had resolved file_picker to
3.0.4 — a version predating macOS support, so the picker had no platform
implementation and import could not be reached at all. It could not
resolve higher because share_plus and package_info_plus pin win32 ^6
while file_picker 8 through 11 pin ^5.

Drops the title from the desktop title bar. The sidebar says WebSave a
few pixels below, and the strip that has to stay draggable was spending
itself on a word the window frame already carries.

Deletes build_rust_ios.sh and sync_bridge.sh, both dead since cargokit
builds Rust as part of the Flutter build.
